# Domain docs

Layout **single-context**:

- `CONTEXT.md` en la raíz — lenguaje ubicuo del dominio. Usar sus términos exactos en código, tests, issues y commits. Si introduces o renombras un concepto, actualiza CONTEXT.md en el mismo commit.
- `docs/adr/` — decisiones de arquitectura. Antes de proponer algo que contradiga una ADR, léela; si de verdad debe cambiar, escribe una nueva ADR que la supersede.
