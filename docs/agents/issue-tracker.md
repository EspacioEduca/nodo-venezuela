# Issue tracker

Este repo no tiene remoto todavía: los issues viven como archivos markdown locales bajo `.scratch/<feature>/`.

- Un issue = un archivo `NN-titulo-corto.md` con un H1, descripción y criterios de aceptación.
- El estado se marca con los labels de triage (ver `triage-labels.md`) como línea `labels: ...` al inicio del archivo.
- Al crear el remoto de GitHub, migrar los issues abiertos con `gh issue create` y actualizar este archivo.
